
# USER GUIDE
## Online School Library Management System

### 1. Introduction

This guide explains how students and librarians use the Online School Library Management System.

### 2. Accessing the System

1. Start Apache and MySQL in XAMPP.
2. Open a web browser.
3. Visit:

http://localhost/Online-library/public/index.html

4. The homepage will appear.

### 3. Student User Guide

#### 3.1 Student Registration

1. Open the registration page.
2. Enter your username and password.
3. Submit the registration form.
4. Log in using your registered credentials.

#### 3.2 Student Login

1. Open the login page.
2. Enter your username and password.
3. Click Login.
4. The Student Dashboard will appear.

#### 3.3 Browse E-books

1. Open the Student Dashboard.
2. Click Browse E-books.
3. View the available books.

#### 3.4 Search for Books

1. Open the book listing page.
2. Enter a book title, author, or category in the search field.
3. View the matching results.

#### 3.5 Borrow an E-book

1. Find a book with available copies.
2. Click Borrow.
3. The system records the borrowing.
4. The available copies decrease by one.

#### 3.6 View Borrowing History

1. Open the Student Dashboard.
2. Click My Borrowing History.
3. View borrowed books and due dates.

#### 3.7 Update Reading Progress

1. Open My Borrowing History.
2. Find an active borrowing record.
3. Enter the number of pages read.
4. Click Update Progress.

#### 3.8 Student Logout

1. Click Logout.
2. The system returns you to the login page.

### 4. Librarian User Guide

#### 4.1 Librarian Login

1. Open the login page.
2. Enter librarian credentials.
3. Click Login.
4. The Librarian Dashboard will appear.

#### 4.2 Add a New E-book

1. Open the Librarian Dashboard.
2. Click Add E-book.
3. Enter the title, author, category, file URL, and available copies.
4. Click Add E-book.

#### 4.3 View and Search E-books

1. Click Manage E-books.
2. View the available books.
3. Use the search field to find a specific book.

#### 4.4 Edit an E-book

1. Open Manage E-books.
2. Find the book.
3. Click Edit.
4. Change the required information.
5. Save the changes.

#### 4.5 Delete an E-book

1. Open Manage E-books.
2. Find the book.
3. Click Delete.
4. Confirm the deletion if prompted.

#### 4.6 View Borrowing Records

1. Open the Librarian Dashboard.
2. Click All Borrowing Records.
3. View student borrowing information.

#### 4.7 Return a Borrowed Book

1. Open All Borrowing Records.
2. Find the active borrowing record.
3. Click Return Book.
4. The system records the return and increases available copies by one.

#### 4.8 Librarian Logout

Click Logout to leave the system.

### 5. Important Notes

- Students should use their own accounts.
- Only librarians can manage E-books and process returns.
- Students can borrow books that have available copies.
- Borrowed books have a due date.
- Users should log out after using the system.

### 6. Conclusion

The Online School Library Management System makes it easier for students to access E-books and monitor their reading progress. It also helps librarians manage books and borrowing records efficiently.
